# Security reporting

This repository is currently private. Authorized collaborators should contact the maintainer privately to report a suspected vulnerability. Do not place credentials, private links, or exploit steps in issues, which could become visible if the repository is later made public.

GitHub offers private vulnerability reporting for public repositories. Before changing this repository's visibility, the maintainer should enable it and then direct external reports to the repository's **Security → Report a vulnerability** form. That form is not available while this repository remains private.

This source snapshot is not a hosted service. Deployments are operated independently.
